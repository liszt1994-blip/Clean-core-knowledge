Using SAP BTP Services in the Kyma Environment

With the Kyma environment, you can connect SAP BTP services to your cluster and manage them using the SAP BTP Operator module.

Context

To consume SAP BTP services and use their functionality for building and deploying your own applications, you must create and manage the service instances and bindings. To learn how to do it, see Creating Service Instances and Service Bindings and Deleting Service Bindings and Service Instances.

For an example of how to use a service, see Create an SAP S/4HANA Cloud Extensibility Service Instance in the Kyma Environment.
