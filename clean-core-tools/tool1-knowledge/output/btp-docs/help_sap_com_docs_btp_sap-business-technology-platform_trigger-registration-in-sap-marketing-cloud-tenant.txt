Trigger the Registration in the SAP Marketing Cloud Tenant

Use this procedure to trigger the registration process for an SAP Marketing Cloud system that you want to pair with your global account in SAP BTP.

Prerequisites

You are an SAP Marketing Cloud tenant administrator.

Procedure
Log on to the SAP Marketing Cloud tenant, go to Home, Communication Management tab and then choose the Maintain Extensions on SAP BTP tile.
In the Maintain Extensions on SAP BTP screen, in the Extensions section, choose New.
In the Integration Token field, enter the content of the registration token from the SAP BTP cockpit.
Choose Save. A new entry in the table appears with status Enabling.
After the integration has finished successfully, you can refresh the table.

The status of the integration should have changed to Enabled.
