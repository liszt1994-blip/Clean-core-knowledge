Edit Space Members

Remove existing roles or assign new roles to a space member in the SAP BTP cockpit.

Prerequisites

You have the Space Manager or Org Manager role.

The users exist in a trusted platform identity provider.

For more information, see About User Management in the Cloud Foundry Environment.

Procedure
Navigate to Cloud Foundry  Spaces in the SAP BTP cockpit. For more information, see Navigate to Orgs and Spaces.
Choose the space in which you'd like to edit the space roles of any of its members.
In the navigation area, choose Space Members.
The screen displays all members currently assigned to the space in a list.
Choose  (Edit).
Select or unselect the space roles you want to assign or remove.

For more information, see About Roles in the Cloud Foundry Environment.

Choose Save.

The changes you make to the roles of a member take effect immediately.
