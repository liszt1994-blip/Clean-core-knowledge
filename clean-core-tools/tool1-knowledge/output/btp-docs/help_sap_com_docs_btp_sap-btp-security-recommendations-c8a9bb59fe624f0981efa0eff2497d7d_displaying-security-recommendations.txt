Displaying Security Recommendations

We've numerous recommendations for SAP BTP and it can be hard to see just the ones you want. Here we try to give you some tips on how to display just the information you want to see.

Too Many Columns

On smaller screens, this table is difficult to display. We've the following suggestions that can help:

Hide the side panes of the SAP Help Portal. The side panes enable you to navigate the structure of the documentation or provide feedback. To use more screen real estate for the content, close these panes.

The following figure shows the controls used to close the side panes.

Once you find the information you need, hide the columns you don't need.

Saving and Sharing Searches

The table already provides filters for the table as a whole and within some of the columns. Unfortunately you can't save those searches directly from the SAP Help Portal. However, you can replicate the use of these filters with URL parameters. Then save these filter configurations as URLs and share them.

The table as a whole and the filters have their own names, which you provide in the URL parameters.
